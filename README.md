# ДРТ-2026 · тренажёр

Один автономный HTML-файл для подготовки к ДРТ: **370 заданий по 10 предметам**, официальные решения, частичный зачёт и точный перевод в 100-балльную шкалу РИКЗ.

## Открыть

- GitHub Pages: **https://hubitski.github.io/drt2026/**
- Локально: скачать `index.html` и открыть в Chrome/Safari/Edge. Интернет не нужен.
- Источники и права: [`sources.html`](sources.html).

## Что внутри

- Русский, белорусский, физика, математика, химия, биология, история Беларуси, обществоведение, география, английский.
- Часть A — выбор вариантов; часть B — краткий ответ.
- Таймер, навигация, автосохранение прогресса, результаты, разбор каждого задания.
- Официальный тестовый балл 0–100 + первичный балл с частичным зачётом.
- Тёмная/светлая тема, мобильная вёрстка, просмотр изображений с масштабом.

## Источники

Задания, решения и изображения взяты из открытых PDF РИКЗ:

- `https://result.rikc.by/ru/free/consult/{01,02,03,04,05,06,07,11,12,13}.pdf`
- `https://result.rikc.by/ru/free/fb__26n.pdf` — схема начисления первичных баллов
- `https://result.rikc.by/ru/free/calc.html` и `https://result.rikc.by/ru/free/test.php` — таблицы перевода
- `https://teenage.by/article/kak-projti-distancionnoe-rt` — структура ДРТ

Полный список с прямыми ссылками — в [`sources.html`](sources.html).

## Права

Материалы находятся в открытом доступе на сайте РИКЗ и используются в образовательных целях для подготовки к ДРТ. Права на задания, решения и изображения принадлежат РИКЗ. Проект не связан с РИКЗ и не является официальным продуктом. Если вы правообладатель и считаете публикацию нарушением, создайте Issue в репозитории — материал будет удалён.

## Пересборка

Исходники (PDF, скрипты извлечения, шаблон) в репозитории не публикуются; здесь только собранный HTML.
